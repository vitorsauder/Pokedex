### 🗺️ PokéDex - Visão de Projeto

Uma aplicação web interativa voltada para o mundo Pokémon, desenvolvida como projeto acadêmico para listagem, busca e gerenciamento de coleções personalizadas dos Pokémons.

### 🎯 Sobre o Projeto

O objetivo deste projeto é construir uma PokéDex moderna que consome dados reais e completos da [PokéAPI](/url?sa=i&source=web&rct=j&url=https://pokeapi.co/&ved=2ahUKEwjEj_SrpKWWAxW8pJUCHaL4NTUQg5wRegYIAAgIECI&opi=89978449&cd&psig=AOvVaw17As209-anQ_VPz-YFuzKQ&ust=1786974349624000). A aplicação permite aos usuários explorar o ecossistema Pokémon, salvar seus favoritos em uma coleção persistente no navegador e alternar a identidade visual do sistema através de um tema customizável. 

O projeto ainda está em andamento!
